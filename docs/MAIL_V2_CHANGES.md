## 採点・保存・移行

- C1～C6=10点、S1～S4=8点、B1～B2=2点の全12項目。特別加点は0/1で20点の内数。得点はアプリが項目合計－減点（下限0）で計算。Brain側合計は無視。
- 引用の原文一致、加点根拠必須、既知の「】【」連結補正、NG文脈判断、3回の最頻値／全異点なら中央値を維持。
- 新しい問題文・基準・想定解は `lib/mail-reference-v2.json`。旧referenceと旧採点コードは履歴用として維持。
- 既存の選択問題IDを維持して、新規開始から新版の問題文・採点版を配信する。旧版の保存設定は上書きせず保持し、新版の選択・編集保存時は新しい問題版として保存する。旧設定で独自編集していた問題文は新規開始には適用せず、新版の本文に切り替える。
- 開始時の問題にはrubricVersionも持たせる。変更前に開始済みの受験は旧問題版・旧配点を使用。旧プリセット版・UUIDの編集アーカイブのどちらも解決する。
- 新版出題に旧版の採点結果が返った場合は、履歴読み出し時も含め版不一致として未確定にする。過去の旧出題結果は当時の項目ID・配点で解析・表示・Excel出力する。
- 管理画面に新版の共通・設問別・特別加点・減点の内訳と採点基準版を表示。Excel採点一覧にも採用回の内訳・基準版を追加し、全3回の項目点と採用回のみのコメント・引用を維持。

## BrainAPI側で設定するもの

`docs/BRAIN_MAIL_GRADING_PROMPT.txt` の「【設定プロンプト】」以降で既存指示を置き換える。メール用Project ID・URL・キーは変更不要。アプリは各リクエストにも問題番号・採点版・対象基準・引用ルール・想定解・回答・NG候補を含める。

アプリからBrainAPIプロジェクトの設定を変更する機能はない。古い上位指示が新しい項目IDや配点を上書きしないよう、設定を更新してから本番の採点検証を行う。
